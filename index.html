瓦纳卡湖畔 5 个拍照点
瓦纳卡孤独树 · That Wānaka Tree经典湖中柳树机位。风小时湖面更容易平静，广角可把湖与雪山一起收入画面。
瓦纳卡湖滨步道 · Lakefront从镇中心沿湖向西走，是串联多个机位的主线，适合湖景、人物和远山。
湖边长椅 · Wānaka Bench更偏氛围感人像，不必锁定某一把长椅；沿湖选择面向雪山、背景干净的位置即可。
瓦纳卡站公园 · Wānaka Station Park湖边安静公园，适合花园、湖景与人物照，也可顺路进入瀑布溪步道。
瀑布溪步道 · Waterfall Creek Track沿湖延伸的轻松步道，可以向 Waterfall Creek 方向走；不需要为了拍照一定走完整段。
推荐顺序：湖滨步道 → 瓦纳卡孤独树 → 瓦纳卡站公园 → 瀑布溪步道；湖边长椅作为沿途补拍点。只拍照建议留 1.5–2 小时；想多走一段步道建议留 2–2.5 小时。
季节提醒：10 月 27 日不要把鲁冰花花海作为预期，主要看湖景、雪山和春季植被。
Plan B：如果 D4 早晨道路或天气耽搁，优先保留湖滨步道、孤独树及瓦纳卡站公园，缩短瀑布溪步道；尽量别压缩皇后镇当晚休息。皇冠山脉公路天气不佳时，可考虑经克伦威尔绕行。

10 月下旬到 11 月初属于南岛春季。
基督城春季常见约 6–17°C，皇后镇约 4–16°C；特卡波、库克山与峡湾地区更冷、更容易遇到风雨。建议按照“速干内层 + 保暖中层 + 防风防水外层”的三层穿法准备，不要只按城市气温打包。

证件与入境

  • 护照：四人分别确认护照有效，并确保姓名、护照号与机票 / NZeTA / 签证信息一致。
  • 签证或 NZeTA：截至 2026 年 9 月，中国护照持有人如果从澳大利亚直接飞往新西兰，并持符合条件的澳洲签证，或为澳洲永久居民，可按现行规则申请 NZeTA；不符合条件则需另行申请访客签证。澳洲公民通常不需要 NZeTA。
  • NZeTA 时间：官方建议至少在出发前 72 小时申请；由于中国游客从澳洲出发的便利政策属于有明确期限的安排，建议出发前 2–4 周再次核对政策。
  • 新西兰旅客申报 NZTD：每个人都要完成 New Zealand Traveller Declaration，入境前填写。
  • 旅游保险：建议覆盖医疗、航班取消 / 延误，并确认跳伞等高空活动是否属于承保范围。

中国驾照在新西兰自驾

  • 中国驾照原件：必须为当前有效的实体驾照，开车时随身携带。
  • 英文翻译：中国驾照不是英文，因此还需要准确的英文翻译。NZTA 接受其授权翻译机构出具的翻译；中国公证处出具的翻译文件也可能被接受。
  • 不要只带所谓“国际驾照翻译认证件”：核心要求是“有效中国驾照原件 + 合规英文翻译 / 符合规定的 IDP”。租车公司还可能有比法律更严格的文件要求，所以订车前要看条款。
  • 租车文件：带主驾驶信用卡、驾照原件、翻译件、护照；如多人轮流驾驶，预订时全部登记为附加驾驶人。

衣物：按三层穿法打包

城市 / 湖区长袖或 T 恤 + 抓绒 / 薄羽绒，早晚加外套
库克山保暖中层 + 防风防水硬壳，帽子和手套放包里
米尔福德优先雨衣和防水鞋；下雨是常态之一
  • 速干或美利奴贴身层 3–4 件，可轮换清洗。
  • 抓绒 / 羊毛中层 1 件，轻薄羽绒或保暖夹克 1 件。
  • 带帽的防风防水外套 1 件，建议真正防水而不是只有“防泼水”。
  • 速干长裤 / 徒步裤 1–2 条；城市休闲裤另备 1 条即可。
  • 保暖帽或薄针织帽、轻薄手套；库克山早晚和大风时很有用。
  • 遮阳帽、太阳镜、SPF 50+ 防晒霜、润唇膏。

鞋子：这趟最重要的是徒步鞋

  • 主力鞋：每人一双已经磨合好的徒步鞋 / 越野鞋；胡克谷步道正常条件下不需要重型登山靴，但建议鞋底抓地好、最好有一定防水性。
  • 备用鞋：一双轻便运动鞋 / 休闲鞋，城市、开车和晚餐时使用。
  • 袜子：美利奴羊毛或合成纤维徒步袜 2–3 双，避免纯棉袜长时间徒步。
  • 特殊天气：库克山天气变化很快，10 月下旬仍可能结冰；临近出发查看 DOC 路况，如近期积雪 / 结冰明显，再考虑微型冰爪和登山杖。

随身与徒步必备

  • 20–30L 日用背包；最好加防雨罩或包内防水袋。
  • 每人至少 1L 水壶，库克山徒步带足饮水和高能量零食。
  • 墨镜、遮阳帽、防晒霜；库克山雪山环境反光明显。
  • 驱虫液：尤其米尔福德峡湾 / 峡湾地区，沙蝇明显。
  • 基础急救包、创可贴、消毒用品、止痛药、个人处方药、抗过敏药；另加水泡贴。
  • 充电宝、车载充电器、数据线；建议带车载手机支架。
  • 手机提前下载离线地图；米尔福德公路及山区会有无信号路段。
  • 纸巾 / 少量厕纸、免洗洗手液、垃圾袋。
  • 可选：轻量登山杖、头灯 / 小手电、应急保温毯。

入境生物安全：徒步鞋要特别注意

  • 出发前彻底清洁徒步鞋：鞋底、鞋缝不要残留泥土、种子和植物碎屑。
  • 用过的户外装备要申报：新西兰要求申报曾用于徒步、露营、钓鱼、水上活动等的户外装备。
  • 食品也要谨慎：肉类、水果、蜂蜜、种子、草药、木制品等可能属于风险物品；带了就按 NZTD 如实申报。
  • 鞋子放容易拿的位置：如需检查，方便现场取出，不要压在行李最底层。

自驾实用准备

  • 新西兰靠左行驶、右舵车；第一天刚落地不要安排长距离驾驶。
  • 每 2 小时左右休息一次，不用为了赶导航时间连续开。
  • 租车时优先确认：全险 / 自付额、轮胎与玻璃、道路救援、附加驾驶人、取消政策。
  • 3 个 28 寸箱 + 4 成人，选车时一定看真实后备箱空间，不只看“5 座”。
  • 米尔福德当天从蒂阿瑙满油出发，并携带水和零食；蒂阿瑙到米尔福德之间没有公共加油站。
  • 出发前下载 NZTA Journey Planner；山区天气不好时不要机械照着地图 ETA 赶路。

天气判断原则

南岛春季天气变化快。库克山所在高山环境全年都可能出现强风、大雨、降雪和快速降温；米尔福德位于高降雨区，下雨不一定需要取消游船，反而常能看到更多瀑布。每天早上同时看天气预报、DOC 步道状态和 NZTA 路况，再决定是否执行主计划。
